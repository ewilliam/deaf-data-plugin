# Deaf Data Lab plugin

The public distribution repository for the Deaf Data Lab plugin for Codex and Claude Code.

**Status: release preparation.** The installable plugin bundle is being validated and has not been published here yet.

The aggregate data service is live at https://deaf-data.vercel.app, with a read-only MCP endpoint at https://deaf-data.vercel.app/mcp. It supports discovery, definitions, geography lookup, statistical queries, historical comparisons, and complete CSV/JSON exports.

This repository will contain only the plugin skills, client manifests, marketplace catalogs, installation documentation, and license. Application code, data storage credentials, private datasets, and application repository history remain separate.

Before the first supported release, the client workflows and file delivery must be verified and the required user-comprehension review completed. A working service connection alone does not establish plugin acceptance.

Questions and support: https://github.com/ewilliam/deaf-data-plugin/issues
